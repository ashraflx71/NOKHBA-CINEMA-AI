# NOKHBA CINEMA | نخبة سينما

معرض ومجلة سينمائية عربية تحتفي بنجوم الشاشة العالميين، بروح تحريرية مستوحاة من أناقة السينما الأوروبية.

## الرؤية المعتمدة
- معرض بصري لصور حقيقية لنجوم وممثلي وممثلات السينما العالمية.
- طابع أوروبي راقٍ: أسود عميق، ذهبي هادئ، وصياغة تحريرية سينمائية.
- واجهة عربية RTL ومتجاوبة مع الهاتف.
- تصنيفات للنجوم والنجمات والكلاسيكيات، وعارض صور مكبّر.
- إضافة الصور تدريجيًا مع توثيق المصدر واسم المصور والترخيص وشروط الاستخدام.

## ملفات الواجهة
- `index.html`: الصفحة الرئيسية ومعرض النجوم.
- `style.css`: الهوية البصرية والتصميم المتجاوب.
- `app.js`: تصفية المعرض وعارض الصور.

## مصادر الصور وحقوق الاستخدام
تستخدم النسخة الافتتاحية صورًا من Wikimedia Commons. لكل صورة صفحة مصدر منفصلة توضح المؤلف والترخيص؛ يجب إبقاء الإسناد المطلوب والالتزام بشروط الترخيص عند إعادة الاستخدام. وجود صورة على Commons لا يعني أن جميع الصور هناك متاحة بلا شروط. يجب مراجعة صفحة كل ملف قبل إضافة صور جديدة أو استخدامها تجاريًا.

## قواعد المشروع
- هذا المشروع مستقل تمامًا عن متجر NOKHBA ومنصة التسوق.
- لا نستخدم صورًا مولّدة أو وجوهًا خيالية على أنها صور نجوم حقيقيين.
- لا نعرض صورة دون التحقق من المصدر والترخيص.
- لا نضع مفاتيح API أو أسرارًا في ملفات الواجهة أو GitHub.
- لا ندّعي أن الموقع نُشر أو اختُبر على الرابط الحي إلا بعد التحقق.

## الحالة
تم تحديث الواجهة الرئيسية إلى معرض سينمائي افتتاحي. يلزم التحقق من نشر التغييرات على Cloudflare، ثم اختبار تحميل الصور والعارض والتصفية على الهاتف.
