# NOKHBA CINEMA AI | نخبة سينما

مشروع مستقل تمامًا عن متجر NOKHBA. هذا المستودع مخصص لاستوديو إنشاء الصور والفيديو بالذكاء الاصطناعي، ولا يحتوي على ملفات أو بيانات منتجات التسوق.

## الرؤية
استوديو عربي باتجاه RTL وواجهة داكنة بلمسات ذهبية، يحول وصف المستخدم إلى صور ومقاطع فيديو سينمائية، مع اختيار النموذج ومعاينة النتائج وحفظها.

## النطاق الأولي
- استوديو الصور.
- استوديو الفيديو.
- اختيار النموذج وإعدادات التوليد.
- عرض النتيجة وتنزيلها.
- تصميم PWA قابل للتثبيت.
- لاحقًا: حسابات المستخدمين، سجل الطلبات، التسعير والدفع المسبق، والتسليم الآلي بعد نجاح الدفع.

## النماذج التي جرى تحديدها مبدئيًا
- MiniMax H3 Image.
- MiniMax H3 Image Highspeed.
- Seedance 1 Pro Fast.
- `bytedance/seedance-1.5-pro`.

وجود الاسم في القائمة لا يعني أن النموذج متاح تلقائيًا عبر كل حساب أو binding؛ يجب التحقق من دعم Cloudflare الحالي وإعدادات الحساب قبل تفعيل كل مسار.

## البنية المقترحة
- `index.html`: واجهة الاستوديو.
- `assets/`: الأيقونات والصور الثابتة.
- `css/`: الأنماط.
- `js/`: منطق الواجهة.
- `functions/api/`: نقاط API على Cloudflare Pages.
- `docs/`: التوثيق وخطة العمل.

## قواعد الأمان والتشغيل
- لا تضع مفاتيح API أو أسرار الدفع في ملفات الواجهة أو GitHub.
- تمر كل طلبات التوليد عبر backend، مع التحقق من المدخلات وحدود الاستخدام.
- لا تعتبر الطلب مدفوعًا اعتمادًا على عودة المتصفح؛ يجب التحقق من إشعار الدفع من الخادم.
- لا يبدأ التوليد المدفوع إلا بعد تأكيد الدفع من مزود الدفع.
- لا نعرض سعرًا أو مدة أو دقة على أنها مضمونة قبل اختبارها والتحقق من المزود.
- لا ننسخ ملفات متجر NOKHBA إلى هذا المستودع.
